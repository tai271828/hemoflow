historical record referenced by `doc/VV/hemoflow_VV.ipynb`.

Superseded by the automated, parametric case
`tests/verification/vv_cases/straight_tube/` (see
`tests/verification/README.md`), which generates its geometry, asserts
tolerances, and tracks regression baselines.
